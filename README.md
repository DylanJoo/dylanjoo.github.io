# dylanjoo.github.io

Minimal one-page academic site, built by GitHub Pages (no Actions build needed).

| To change | Edit |
| --- | --- |
| Bio, links layout | `index.html` |
| Name, email, social URLs | `_config.yml` (`author:`) |
| Photo | `assets/profile.jpg` |
| News | `_data/news.yml` |
| Publications | `_data/publications.bib` → `publications.yml` is regenerated by the *Update publications* workflow on push (or run `python scripts/bib2yaml.py`) |
| CV / PDFs | `files/` |
| Styling | `assets/style.css` |

Local preview (Ruby ≥ 3.1): `bundle install && bundle exec jekyll serve`.
